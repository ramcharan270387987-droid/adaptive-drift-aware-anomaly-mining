# Faculty submission checklist

Checked items reflect verified repository evidence. Unchecked items require the student or institution to supply details or approve a final deliverable.

## Repository

- [x] Verify the final `work` candidate against its upstream revision.
- [x] Verify tests and clean Git status.
- [x] Scan indexed text and artifact paths for common credential and data leaks.
- [x] Confirm README navigation and reproduce setup in a fresh worktree.
- [ ] Review and merge the approved pull request through the normal repository process.

## Project report

- [ ] Fill student name and registration or roll number.
- [ ] Fill programme, department, institution, and guide or supervisor name.
- [ ] Fill academic year and submission date.
- [ ] Obtain required signatures if applicable.
- [ ] Review the completed PDF after inserting institutional details.

## Demo

- [x] Verify the local dashboard and Spark demonstration.
- [x] Prepare a self-contained offline fallback with captured output.
- [x] Verify the 5–7 minute sequence against recorded and live development evidence.
- [ ] Rehearse the narration on the actual demonstration machine.

## Presentation

- [x] Prepare the faculty presentation outline and viva question set.
- [x] Review published figures for readability.
- [ ] Build the final slide deck in the required presentation template.
- [ ] Review the viva answers and rehearse with the final slides.

## IEEE-style manuscript

- [x] Verify the references, evidence, and citation numbering.
- [ ] Add author name(s), affiliation, institution, and email.
- [ ] Choose the venue and apply its current template and submission rules.
- [ ] Add acknowledgements if applicable and complete author proofreading.

## Submission archive

- [x] Assemble source, report and manuscript drafts, presentation material, demo fallback, and reproduction instructions.
- [ ] Replace report and manuscript drafts with the approved, completed PDFs.
- [ ] Include the final slide deck and any required institutional forms.
- [ ] Verify the final archive and submit through the applicable institutional channel.
